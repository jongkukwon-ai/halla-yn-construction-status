# 착공·인허가 통계 갱신 도구

`construction/trend.html`(영남권 착공·인허가 통계)의 데이터를 새 달로 갱신하는 스크립트입니다.
화면 코드는 건드리지 않고, 파일 안의 데이터 세 줄(`const DATA`, `const SUB`, `const SUB_VALID`)만 교체합니다.

## 언제 돌리나
- **시도 통계**: 국토교통부 통계누리(stat.molit.go.kr)에 새 달이 공표된 뒤. 보통 한 달 이상 늦게 나옵니다(예: 8월분은 10월 초에 확인됨).
- **시·군·구**: 건축HUB(hub.go.kr) 대용량 제공 서비스의 「기본개요」 파일이 새로 올라온 뒤. 매월 20일 무렵 전월분이 올라옵니다.
- 두 자료 모두 같은 달까지 나온 뒤에 돌리는 것이 좋습니다. 원자료가 덜 들어온 달이 있으면 스크립트가 경고를 출력합니다.

## 실행
Python 3.9 이상, 추가 설치 없음(표준 라이브러리만 사용). 로그인·API 키가 필요 없는 공개 자료만 씁니다.

```bash
cd construction/tools

# 원자료 zip을 이미 받아 둔 경우
python update_trend.py --end 202608 --permit-zip 건축인허가_기본개요.zip --housing-zip 주택인허가_기본개요.zip

# 원자료 zip도 스크립트가 받게 하는 경우 (건축 약 440MB + 주택 약 7.5MB)
python update_trend.py --end 202608 --download --workdir D:/temp

# 결과만 보고 파일은 고치지 않기
python update_trend.py --end 202608 --permit-zip ... --housing-zip ... --dry-run
```

- `--end`: 마지막 월(YYYYMM). 국토부 통계에 아직 없는 달을 주면 멈춥니다. 조회 기간은 항상 이 달까지 60개월입니다.
- 집계에 몇 분 걸립니다(건축 원자료 압축 해제 시 약 1.7GB, 전국 650만여 건).
- **원자료 zip은 저장소에 올리지 마세요**(용량 큼, `.gitignore`로 제외).

## 돌린 뒤 직접 고칠 문구 (trend.html)
스크립트가 데이터만 바꾸므로 아래 글자는 직접 고칩니다.
1. 헤더 `조회기간 2021.09~2026.08 (60개월)`
2. 하단 출처: `조회기간 …, 조회일 …`, 잠정치 구간(`2026-01~2026-08 자료는 … '잠정치'`), 검증 비율 범위(`인허가 약 76~90%, 착공 약 45~67%` — 스크립트가 출력한 검증 수치의 최소~최대)
3. 하단 「지역별 누적 조회」 설명의 예시 월과 `데이터 시작(…)부터 18개월이 채워지는 …부터`
4. 개발명세서(`개발명세서.md`, `construction/trend_개발명세서.md`)의 같은 기간·비율 표기

## 집계 규칙 (2026-09 검증으로 정한 것, 바꾸면 기존 값과 달라짐)
**시도(`DATA`)** — 통계누리 `formId=2202`(착공)·`2200`(허가)의 시도별 「계/계」 합계, 연면적·동수.

**시·군·구(`SUB`)** — 건축HUB 원자료 자체 집계, 연면적만.
1. 건축인허가: 건축구분 **신축만**. (증축·대수선·용도변경 행의 연면적은 건물 전체 면적이라 더하면 공식의 10~28배가 됨)
2. 주택인허가: 세대수·동수가 있고 세대당 10~1,000㎡인 행만. 필지·세대수·면적(100㎡ 단위)이 같은 행은 한 사업으로 묶음(변경 기록 중복). 승인월은 묶음 첫 기록의 사업승인일, 착공월은 묶음 안에서 **실제 착공일**이 적힌 기록. 착공예정일은 쓰지 않음.
3. 인허가 월 = 허가일(주택은 사업승인일), 착공 월 = 실제 착공일.
4. 시·군·구 이름은 대지위치의 두 번째 낱말. 그래서 창원시(5개 구)·포항시(2개 구)는 자동으로 시 단위로 합쳐집니다. 지역 순서는 trend.html의 기존 `SUB` 순서를 따르며, 목록에 없는 새 이름이 나오면 경고합니다.

**검증(`SUB_VALID`)** — 시·군·구 합계를 시도로 더해 공식 통계와 비교한 `[인허가 비율, 인허가 월별 상관, 착공 비율, 착공 상관]`. 화면 안내 문구에 그대로 나옵니다. 착공은 주택 사업의 실제 착공일 기록이 드물어 공식의 절반 안팎으로 잡히는 것이 정상입니다.
