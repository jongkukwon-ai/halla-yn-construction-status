# 착공·인허가 통계 갱신 도구

## 자동 갱신 (2026-10-13~, 기본 방식)
GitHub Actions(`.github/workflows/trend.yml`)가 매일 09:30(KST) `auto_update.py`를 실행합니다.
- 세움터 「인허가정보집계」(로그인 불필요) 목록에서 최신 월별 시군구 파일과 연도별 확정치를 확인하고, 국토부 통계누리에도 그 달이 나왔으면 갱신합니다(보통 다음 달 말).
- 시도 통계(`DATA`)는 통계누리, 시·군·구(`SUB`)는 세움터(확정치가 나온 해는 확정치 zip, 그 뒤는 월별 잠정치)로 만들고, 시·군·구 합이 시도 통계와 0.5% 안에서 맞지 않으면 아무것도 바꾸지 않고 실패로 끝납니다.
- 조회기간·조회일·잠정치 구간·누적 예시 월 문구도 자동으로 바꿉니다. 새 연도 확정치가 올라오면(익년 9월경) 그 해 잠정치를 확정치로 자동 교체합니다.
- **착공 2021-09~2026-07은 영남지사 사업계획 백데이터(세움터 월별 잠정치 원본) 값으로 고정**되어 있습니다(`SUB_SRC.착공_백데이터`). 자동 갱신은 이 구간 착공을 확정치로 덮어쓰지 않고, 시도 합계 검증에서도 뺍니다. 고정을 풀려면 `SUB_SRC`에서 `착공_백데이터`를 지우면 됩니다.
- **전국 조회**(`NAT`·`NAT_SUB`·`NAT_VALID`)도 같은 세움터 파일(전국 수록)과 통계누리 전국 시도 통계로 함께 갱신하고 같은 검사를 합니다. 시도는 현재 행정구역 16곳(광주+전남 → 전남광주, 군위 → 대구), 시·군·구는 사업계획 백데이터 「비교단위」 규칙(`import_seumter.nat_place`: 일반구 → 시, 인천 2026.7 개편 구는 권역). 처음 보는 지역명이 나오면 로그에 "확인 필요"로 표시하고 목록 끝에 붙입니다.
- 수동 실행: GitHub 저장소 → Actions → 「착공·인허가 통계 자동 갱신」 → Run workflow(필요하면 force 체크).
- 아래의 `update_trend.py`·`import_seumter.py`는 자동 갱신이 막혔을 때 쓰는 수동 도구입니다.

`construction/trend.html`(영남권 착공·인허가 통계)의 데이터를 새 달로 갱신하는 스크립트입니다.
화면 코드는 건드리지 않고, 파일 안의 데이터 세 줄(`const DATA`, `const SUB`, `const SUB_VALID`)만 교체합니다.

## 언제 돌리나
- **시도 통계**: 국토교통부 통계누리(stat.molit.go.kr)에 새 달이 공표된 뒤. 보통 한 달 이상 늦게 나옵니다(예: 8월분은 10월 초에 확인됨).
- **시·군·구**: 건축HUB(hub.go.kr) 대용량 제공 서비스의 「기본개요」 파일이 새로 올라온 뒤. 매월 20일 무렵 전월분이 올라옵니다.
- 두 자료 모두 같은 달까지 나온 뒤에 돌리는 것이 좋습니다. 원자료가 덜 들어온 달이 있으면 스크립트가 경고를 출력합니다.

## 실행
Python 3.9 이상, 추가 설치 없음(표준 라이브러리만 사용). 로그인·API 키가 필요 없는 공개 자료만 씁니다.

```bash
cd construction/tools

# 원자료 zip을 이미 받아 둔 경우
python update_trend.py --end 202608 --permit-zip 건축인허가_기본개요.zip --housing-zip 주택인허가_기본개요.zip

# 원자료 zip도 스크립트가 받게 하는 경우 (건축 약 440MB + 주택 약 7.5MB)
python update_trend.py --end 202608 --download --workdir D:/temp

# 결과만 보고 파일은 고치지 않기
python update_trend.py --end 202608 --permit-zip ... --housing-zip ... --dry-run
```

- `--end`: 마지막 월(YYYYMM). 국토부 통계에 아직 없는 달을 주면 멈춥니다. 조회 기간은 항상 이 달까지 60개월입니다.
- 집계에 몇 분 걸립니다(건축 원자료 압축 해제 시 약 1.7GB, 전국 650만여 건).
- **원자료 zip은 저장소에 올리지 마세요**(용량 큼, `.gitignore`로 제외).

## 돌린 뒤 직접 고칠 문구 (trend.html)
스크립트가 데이터만 바꾸므로 아래 글자는 직접 고칩니다.
1. 헤더 `조회기간 2021.09~2026.08 (60개월)`
2. 하단 출처: `조회기간 …, 조회일 …`, 잠정치 구간(`2026-01~2026-08 자료는 … '잠정치'`), 검증 비율 범위(`인허가 약 76~90%, 착공 약 45~67%` — 스크립트가 출력한 검증 수치의 최소~최대)
3. 하단 「영남권 누적 조회」·「전국 누적 조회」 설명의 예시 월과 `데이터 시작(…)부터 18개월이 채워지는 …부터`
4. 개발명세서(`개발명세서.md`, `construction/trend_개발명세서.md`)의 같은 기간·비율 표기

## 집계 규칙 (2026-09 검증으로 정한 것, 바꾸면 기존 값과 달라짐)
**시도(`DATA`)** — 통계누리 `formId=2202`(착공)·`2200`(허가)의 시도별 「계/계」 합계, 연면적·동수.

**시·군·구(`SUB`)** — 건축HUB 원자료 자체 집계, 연면적만.
1. 건축인허가: 건축구분 **신축만**. (증축·대수선·용도변경 행의 연면적은 건물 전체 면적이라 더하면 공식의 10~28배가 됨)
2. 주택인허가: 세대수·동수가 있고 세대당 10~1,000㎡인 행만. 필지·세대수·면적(100㎡ 단위)이 같은 행은 한 사업으로 묶음(변경 기록 중복). 승인월은 묶음 첫 기록의 사업승인일, 착공월은 묶음 안에서 **실제 착공일**이 적힌 기록. 착공예정일은 쓰지 않음.
3. 인허가 월 = 허가일(주택은 사업승인일), 착공 월 = 실제 착공일.
4. 시·군·구 이름은 대지위치의 두 번째 낱말. 그래서 창원시(5개 구)·포항시(2개 구)는 자동으로 시 단위로 합쳐집니다. 지역 순서는 trend.html의 기존 `SUB` 순서를 따르며, 목록에 없는 새 이름이 나오면 경고합니다.

**검증(`SUB_VALID`)** — 시·군·구 합계를 시도로 더해 공식 통계와 비교한 `[인허가 비율, 인허가 월별 상관, 착공 비율, 착공 상관]`. 화면 안내 문구에 그대로 나옵니다. 착공은 주택 사업의 실제 착공일 기록이 드물어 공식의 절반 안팎으로 잡히는 것이 정상입니다.

## 세움터 시군구 집계 반영 (import_seumter.py) — update_trend.py 다음에 꼭 실행
2026-10-13부터 시·군·구 값(허가·착공, 2021-09~)은 세움터 「인허가정보집계」의 공식 시군구 집계를 씁니다. 2021~2025년은 연도별 확정치 zip(「YYYY년_월별_인허가현황(확정치).zip」), 2026년은 월별 파일입니다.
`update_trend.py`는 SUB를 건축HUB 원자료로 새로 만들기 때문에, 돌린 뒤에는 세움터 파일을 다시 덮어써야 합니다.

```bash
python import_seumter.py "<착공 백데이터.xlsx>" "<시군구별_용도별_건축허가_착공_준공_현황(2026년08월).xlsx>" "<…(2026년09월).xlsx>"
```
- 백데이터(시트 '데이터', 착공만, 2018~)와 세움터 월별 파일(허가·착공)을 섞어 줄 수 있고, 같은 달이 겹치면 **뒤에 준 파일**이 이깁니다.
- 매달: 세움터에서 그 달 「시군구별_용도별_건축허가_착공_준공_현황」을 받아 → `update_trend.py --end YYYYMM ...` → `import_seumter.py <연도별 확정치 zip들> <2026년 월별 파일 전부>`. 확정치가 새로 나오면(익년 9월 공표) 그 해 zip으로 바꿔 넣습니다.
- 2026-10-13 반영 시: 2021~2025 확정치 zip 5개 + 2026-01~08 월별 파일로 120개 월·지표 모두 시도 통계와 0.05% 안에서 일치함을 확인.
- 시·도가 직접 처리해 구·군이 빈 행은 「시·도 직접」, 창원시·포항시 일반구는 시로 합칩니다. 바꾼 달은 `SUB_SRC`에 기록되어 화면 안내문에 표시됩니다.
- 세움터 월별 값은 잠정치라 시도 확정치(통계누리)보다 작을 수 있습니다(대구 2021년은 약 3분의 1).
- `--national`을 붙이면 전국 조회용 `NAT`·`NAT_SUB`·`NAT_VALID`도 같이 만듭니다(통계누리 접속). 2026-10-13 반영 명령:
  `python import_seumter.py --national <2021~2025 확정치 zip 5개> <2026년 01~08월 파일> <착공 백데이터.xlsx>` — 백데이터를 **맨 뒤**에 줘야 착공 2021-09~2026-07이 백데이터 값으로 남습니다.
- 기존 `SUB_SRC`의 `확정`·`착공_백데이터` 표시는 그대로 유지됩니다.
