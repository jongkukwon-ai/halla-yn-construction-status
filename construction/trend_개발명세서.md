## 1. 프로그램 개요

### 목적
부산·울산·대구·경남·경북 5개 시도의 **건축 착공·인허가 통계**(국토교통부 공식 통계)를 한눈에 볼 수 있는 내부 조회용 웹페이지입니다. 영업/영업관리 담당자가 별도 로그인이나 프로그램 설치 없이 브라우저로 바로 열어, 지역별 착공·인허가 추이를 시멘트 수요 예측 등에 참고할 수 있도록 만들었습니다.

### 핵심 기능
| 기능 | 설명 |
|---|---|
| 지표 전환 | 상단 토글로 **연면적(㎡)** / **동수(건)** 기준을 전환 |
| 영남권 합계 헤드라인 차트 | 5개 시도 합산 기준 월별 착공 vs 인허가 추이(60개월), 마우스오버 시 툴팁 |
| 시도별 미니 차트 5개 | 부산·울산·대구·경남·경북 각각의 추이(지역별 규모 차이가 커서 카드마다 축을 자체 스케일로 조정) |
| 전년동월비(YoY) 배지 | 최신월 착공량의 전년 동월 대비 증감률 |
| 월별 상세표 | 60개월 × 5개 지역 × 2개 지표(착공/인허가)의 원자료를 표로 펼쳐보기 |
| EXCEL 다운로드 | 위 상세표를 현재 선택된 지표 기준으로 엑셀 파일(.xlsx)로 다운로드 |
| 지역별 조회 | 지역(5개 시도 다중선택)·기간(시작월~종료월, 데이터 보유 범위 60개월 내)을 골라 착공·인허가를 조회. 여러 지역 선택 시 "선택지역 합계" 열과 "기간 합계" 행을 자동 계산. 표 펼치기 / EXCEL 다운로드 지원 |

### 데이터 성격상 유의점
이 페이지는 **아파트만이 아닌 상업·공업 등을 포함한 전체 건축물** 통계입니다. 사이트 내 「영남지역 착공현황」 탭(아파트 개별 현장 리스트, `construction/index.html`)과는 **완전히 별개의 자료**이며 서로 연동되지 않습니다.

## 2. 파일 구조

```
construction/
└── trend.html   ← 이 페이지 전부 (HTML + CSS + JS + 데이터가 단일 파일에 포함)
```

- **단일 파일 구조**입니다. 별도의 서버 코드(.py, .js 백엔드), 빌드 스크립트, 설정 파일이 없습니다.
- 데이터(월별 통계 수치)는 파일 안에 `const DATA = {...}` 형태의 JavaScript 상수로 **하드코딩되어 포함**되어 있습니다. 별도의 데이터 파일이나 DB를 읽어오지 않습니다.
- 사이트 홈(`index.html`)의 "영남권 착공·인허가 통계" 카드가 이 파일로 링크됩니다.
- (참고, 배포 파일 아님) 데이터 최초 수집 시 작업용으로 `착공추이/molit_yeongnam.json`, `착공추이/artifact.html` 파일을 로컬에서 사용했으나, 이 둘은 저장소(배포 서버)에 커밋되지 않은 로컬 작업 파일입니다.

## 3. 주요 로직 설명

### 데이터 구조 (`DATA` 상수)
```js
DATA = {
  months:  ["2021-08", ..., "2026-07"],       // 60개월
  regions: ["부산","울산","대구","경남","경북"],
  series: {
    "부산": {
      permit_count: [...], permit_area: [...],   // 인허가: 동수, 연면적
      start_count:  [...], start_area:  [...]    // 착공:   동수, 연면적
    },
    ... // 나머지 4개 지역도 동일 구조
  }
}
```
지역별로 4개의 60칸짜리 숫자 배열(인허가 동수/연면적, 착공 동수/연면적)을 갖는 구조입니다.

### 핵심 함수
| 함수 | 역할 |
|---|---|
| `sumAcrossRegions(field)` | 5개 지역의 특정 지표를 월별로 합산해 "영남권 합계" 배열 생성 |
| `buildChart(container, startArr, permitArr, opts)` | SVG를 직접 그려(외부 차트 라이브러리 미사용) 착공/인허가 두 선 그래프를 렌더링. 헤드라인 차트와 5개 미니 차트가 이 함수 하나를 옵션만 바꿔 공유 |
| `renderStats()` | 최신월 착공/인허가 합계와 전년동월비를 상단 카드에 표시 |
| `renderHeadline()` / `renderRegions()` | 각각 합계 차트 / 지역별 미니 차트 그리드를 그림 |
| `renderTable()` | 월별 상세표를 HTML 테이블로 생성(최신월이 위로 오도록 역순 정렬) |
| `downloadXlsx({title, hdr, rows, footer, sheetName, fileName})` | 두 엑셀 다운로드가 공유하는 공용 함수. 제목행 + 네이비 헤더행 + 데이터행(+합계행)으로 `.xlsx`를 만들어 다운로드 |
| `exportExcelTrend()` | 월별 상세표와 동일한 내용을 `downloadXlsx()`로 내보냄 |
| `queryTable()` | 「지역별 조회」의 선택 지역·기간(`q` 객체)으로 표 데이터(행·선택지역 합계 열·기간 합계 행)를 계산 |
| `renderQuery()` / `renderQueryTable()` | 조회 조건 요약(기간 합계) 문구와 조회 결과 표를 렌더링 |
| `initQuery()` | 지역 칩(체크박스)·기간 선택 박스를 만들고 이벤트 연결. 시작월이 종료월보다 늦어지지 않도록 자동 보정 |
| `yoy(arr)` | 배열의 마지막 값과 13칸 전(전년 동월) 값을 비교해 증감률(%) 계산 |

### 상태 관리
- 전역 변수 `metric` (`'area'` 또는 `'count'`) 하나로 화면 전체(카드·차트·표·지역별 조회·엑셀)의 기준 지표가 결정됩니다.
- 「지역별 조회」의 선택 상태는 전역 객체 `q = { regions: Set, from: 월인덱스, to: 월인덱스 }`에 담깁니다. 버튼 클릭 시 `metric` 값을 바꾸고 `renderAll()`을 다시 호출해 전체를 재렌더링하는 단순 구조입니다.
- 별도의 상태 저장(로컬스토리지, 쿠키, 세션)은 사용하지 않습니다. 새로고침하면 항상 초기값(`metric='area'`, 표 접힘)으로 돌아갑니다.

## 4. DB 사용 여부 및 상세 (중요)

**사내/외부 데이터베이스에 전혀 연결하지 않습니다.**

- 조회(SELECT), 수정(INSERT/UPDATE/DELETE) 등 어떠한 CRUD 동작도 없습니다.
- 접근하는 테이블이 존재하지 않습니다.
- 페이지가 표시하는 모든 수치는 파일 안에 **정적으로 박혀있는 값**이며, 페이지를 열 때마다 매번 동일한 값이 보입니다(수동으로 파일을 갱신하기 전까지).
- 이는 사이트 전체(`halla-yn-construction-status` 저장소)의 공통 설계 방식입니다 — 서버/DB 없이 정적 파일만으로 GitHub Pages에서 서빙됩니다.

## 5. 외부 API 사용 여부 (중요)

### 5-1. 배포된 페이지가 런타임에 호출하는 API
**없습니다.** `trend.html`이 브라우저에 로드된 이후, 실행 중에 어떤 외부 서버로도 데이터 요청(fetch/XHR/AJAX)을 보내지 않습니다. 모든 통계 수치는 위에서 설명한 `DATA` 상수로 이미 파일 안에 포함되어 있습니다.

### 5-2. 외부 CDN 리소스 (데이터 API 아님, 라이브러리 로드)
```html
<script src="https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js"></script>
```
- **ExcelJS**(오픈소스 JS 라이브러리) 한 개만 jsDelivr CDN에서 불러옵니다.
- 용도: "EXCEL 다운로드" 버튼을 눌렀을 때 **브라우저 안에서** 엑셀 파일을 생성하기 위함입니다. 외부로 데이터를 전송하지 않고, 순수하게 클라이언트 사이드에서 파일을 만들어 로컬로 다운로드시킵니다.
- API 키나 인증 정보가 전혀 필요 없는 공개 라이브러리입니다.

### 5-3. 데이터 최초 수집 시 (일회성, 배포 코드에는 미포함)
현재 파일에 박혀있는 수치는 아래 과정으로 **한 번만** 수집해서 파일에 붙여넣은 것이며, 이 호출 코드 자체는 `trend.html`에 들어있지 않습니다(수집용 스크립트는 로컬 작업 후 폐기).

- **출처**: 국토교통부 통계누리(stat.molit.go.kr)의 공개 통계 조회 엔드포인트
  ```
  https://stat.molit.go.kr/portal/stat/data.do?formId=2202&styleNum=838&apprYn=Y&startDate=202108&endDate=202607   (착공)
  https://stat.molit.go.kr/portal/stat/data.do?formId=2200&styleNum=839&apprYn=Y&startDate=202108&endDate=202607   (허가)
  ```
- **인증 방식**: **API 키·로그인 불필요**. 누구나 접근 가능한 공공 통계 조회 엔드포인트로, HTTP GET 요청에 `Referer` 헤더만 포함하면 응답합니다.
- **API 특성상 제약**: 한 번의 조회에 최대 5년(60개월)까지만 가능해, 조회기간이 2021-08~2026-07로 고정되어 있습니다.
- **결론**: 이 페이지와 관련해 어디에도 개인 발급 API 키나 인증 토큰이 저장·사용된 적이 없습니다.

> 참고: 같은 저장소 내 다른 실험(구·군 단위 착공현황 상세조회 시도)을 위해 국토교통부 "건축HUB" API 개인 인증키를 발급받아 테스트한 적이 있으나, **그 결과물은 이 페이지(`trend.html`)에 전혀 반영되지 않았고, 해당 키는 이 파일 어디에도 포함되어 있지 않습니다.**

## 6. 실행 환경 및 방법

### 필요 패키지 / 라이브러리
- **없음(빌드 불필요)**. npm install, pip install 등 어떤 패키지 설치도 필요 없습니다.
- 유일한 외부 의존성은 브라우저가 런타임에 자동으로 불러오는 ExcelJS(CDN)이며, 로컬에 설치할 필요가 없습니다.

### 실행 방법
1. **로컬에서 미리보기**: `construction/trend.html` 파일을 더블클릭하거나 브라우저 주소창에 `file:///...` 경로로 열면 바로 동작합니다(서버 구동 불필요).
2. **배포**: 이 저장소는 **GitHub Pages**로 서빙됩니다. `main` 브랜치에 파일을 커밋·푸시하면 별도 빌드 과정 없이 몇 분 내로 아래 URL에 자동 반영됩니다.
   - https://jongkukwon-ai.github.io/halla-yn-construction-status/construction/trend.html
3. **데이터 갱신 방법**(월 1회 정도 권장): 위 5-3의 두 URL을 `startDate`/`endDate`를 최신 구간으로 바꿔 다시 조회 → 응답 JSON을 지역×월×지표별로 집계 → 파일 안의 `const DATA = {...}` 리터럴을 새 값으로 교체 → 커밋·푸시.

## 7. 주의사항 (유지보수 참고)

1. **조회기간 60개월 고정**: 국토교통부 API 자체가 1회 조회 최대 5년만 허용하므로, 60개월치만 담겨 있습니다. 기간을 늘리려면 여러 번 나눠 조회해 이어붙여야 합니다.
2. **데이터는 스냅샷입니다 — 실시간 아님**: 페이지를 열 때마다 항상 마지막으로 갱신한 시점의 고정값을 보여줍니다. 최신 통계를 반영하려면 반드시 6장의 절차대로 수동 갱신해야 합니다.
3. **최근 구간은 잠정치**: 원 통계 기준 2025-01~2026-07 자료는 "잠정치(p)"로, 이후 확정 공표 시 수치가 소급 정정될 수 있습니다.
4. **구·군 단위 데이터 없음**: 이 통계는 시도 단위까지만 존재합니다(국토부·KOSIS 모두 확인됨). 구·군 단위 세분화는 신뢰할 수 있는 공개 통계원이 없어 구현하지 않았습니다 — 향후 담당자가 "구별로 볼 수 있게 해달라"는 요청을 받으면, 데이터 자체가 없다는 점을 먼저 확인해야 합니다.
5. **아파트 통계 아님**: 상업·공업 등을 포함한 전체 건축물 기준이라, 시멘트 수요와 직결되는 아파트만 보고 싶다면 별도 탭(「영남지역 착공현황」, `construction/index.html`)을 참고해야 합니다. 두 페이지의 숫자를 서로 비교/합산하면 안 됩니다.
6. **외부 CDN 의존**: ExcelJS를 jsDelivr CDN에서 불러오므로, 사내망에서 외부 CDN 접속이 차단되어 있으면 "EXCEL 다운로드" 버튼만 동작하지 않습니다(차트·표 등 나머지 기능에는 영향 없음). 필요 시 해당 CDN 도메인(`cdn.jsdelivr.net`)을 방화벽 허용 목록에 추가해야 합니다.
7. **에러 처리/테스트 코드 없음**: 단일 정적 파일로, 별도의 자동화 테스트나 예외 처리 로직은 최소한으로만 되어 있습니다(ExcelJS 로드 실패 시 alert 정도). 데이터 리터럴을 手작업으로 교체할 때 JSON 문법 오류가 없는지 직접 확인해야 합니다.
8. **개인정보 없음**: 이 페이지가 다루는 데이터는 정부 공개 집계 통계뿐이며, 개인정보·사내 기밀 정보는 포함되어 있지 않습니다.
