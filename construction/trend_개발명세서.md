## 1. 프로그램 개요

### 목적
부산·울산·대구·경남·경북 5개 시도의 **건축 착공·인허가 통계**(국토교통부 공식 통계)를 한눈에 볼 수 있는 내부 조회용 웹페이지입니다. 영업/영업관리 담당자가 별도 로그인이나 프로그램 설치 없이 브라우저로 바로 열어, 지역별 착공·인허가 추이를 시멘트 수요 예측 등에 참고할 수 있도록 만들었습니다.

### 핵심 기능
| 기능 | 설명 |
|---|---|
| 지표 전환 | 상단 토글로 **연면적(㎡)** / **동수(건)** 기준을 전환 |
| 영남권 합계 헤드라인 차트 | 5개 시도 합산 기준 월별 착공 vs 인허가 추이(60개월), 마우스오버 시 툴팁. 왼쪽에 최신월 착공(위)·인허가(아래) 합계 카드. 가로축은 분기(3·6·9·12월) 라벨 |
| 시도별 차트 5개 | 부산·울산·대구·경남·경북 각각의 추이를 한 줄에 2개씩(모바일은 1개) 표시. 가로축은 헤드라인과 같은 분기 라벨. 지역별 규모 차이가 커서 카드마다 세로축을 자체 스케일로 조정 |
| 전년동월비(YoY) 배지 | 최신월 착공량의 전년 동월 대비 증감률 |
| 월별 상세표 | 60개월 × 5개 지역 × 2개 지표(착공/인허가)의 원자료를 표로 펼쳐보기 |
| EXCEL 다운로드 | 위 상세표를 현재 선택된 지표 기준으로 엑셀 파일(.xlsx)로 다운로드 |
| 지역별 조회 | **시도 드롭다운**(다중선택) → **시·군·구 드롭다운**(선택한 시도의 하위 지역, 다중선택. 광역시는 구·군, 경남·경북은 시·군) + 기간(시작월~종료월, 60개월 내)으로 착공·인허가를 조회. 시·군·구를 고르지 않으면 시도 단위 공식 통계, 고르면 원자료 기반 연면적으로 조회. 여러 지역 선택 시 "선택지역 합계" 열과 "기간 합계" 행을 자동 계산. 표 펼치기 / EXCEL 다운로드 지원 |
| 지역별 누적 조회 | 지역별 조회와 같은 시도·시·군·구 선택에 **기준월**(시작~끝)을 고르면, 각 기준월마다 그 달을 포함한 직전 18개월(예: 2026-08 → 2025-03~2026-08) 착공·인허가 누적값을 표시. 18개월이 채워지는 2023-02부터 선택 가능. 표에는 기준월·누적기간·지역별 누적·선택지역 합계 열(누적값끼리 더한 합계행은 의미가 없어 생략). 표 위에 선택지역 합계(1개 지역이면 그 지역)의 기준월별 누적 착공·인허가 꺾은선 그래프(마우스 올리면 값 표시). 표 펼치기 / EXCEL 다운로드 지원 |

### 데이터 성격상 유의점
이 페이지는 **아파트만이 아닌 상업·공업 등을 포함한 전체 건축물** 통계입니다. 사이트 내 「영남지역 착공현황」 탭(아파트 개별 현장 리스트, `construction/index.html`)과는 **완전히 별개의 자료**이며 서로 연동되지 않습니다.

## 3. 주요 로직 설명

### 데이터 구조 (`DATA` 상수)
```js
DATA = {
  months:  ["2021-09", ..., "2026-08"],       // 60개월
  regions: ["부산","울산","대구","경남","경북"],
  series: {
    "부산": {
      permit_count: [...], permit_area: [...],   // 인허가: 동수, 연면적
      start_count:  [...], start_area:  [...]    // 착공:   동수, 연면적
    },
    ... // 나머지 4개 지역도 동일 구조
  }
}
```
지역별로 4개의 60칸짜리 숫자 배열(인허가 동수/연면적, 착공 동수/연면적)을 갖는 구조입니다.

### 데이터 구조 (`SUB`, `SUB_VALID` 상수 — 「지역별 조회」의 시·군·구용)
```js
SUB = {
  "부산": [ ["중구", [인허가 연면적 60칸], [착공 연면적 60칸]], ... ],   // 16개 구·군
  "울산": [...5개 구·군], "대구": [...9개 구·군(군위군 포함)],
  "경남": [ ["창원시", ...], ["진주시", ...], ... ],                      // 18개 시·군 (창원시 = 5개 구 합산)
  "경북": [ ["포항시", ...], ... ]                                         // 22개 시·군 (포항시 = 남·북구 합산)
}
SUB_VALID = { "경남": [0.87, 0.96, 0.63, 0.70], ... }   // [인허가 공식 대비 비율, 월별 상관, 착공 비율, 착공 상관]
```
- 월 순서는 `DATA.months`와 같습니다. 단위는 연면적(㎡)이고 동수는 없습니다.
- `SUB`는 국토부 공식 통계가 아니라 **건축HUB 원자료를 자체 집계한 값**입니다(5-3 참고). `SUB_VALID`는 그 원자료 합계를 시도 단위로 다시 더해 공식 통계(`DATA`)와 비교한 검증 수치로, 화면의 안내 문구에 그대로 표시됩니다.

### 핵심 함수
| 함수 | 역할 |
|---|---|
| `sumAcrossRegions(field)` | 5개 지역의 특정 지표를 월별로 합산해 "영남권 합계" 배열 생성 |
| `buildChart(container, startArr, permitArr, opts)` | SVG를 직접 그려(외부 차트 라이브러리 미사용) 착공/인허가 두 선 그래프를 렌더링. 헤드라인 차트와 5개 미니 차트가 이 함수 하나를 옵션만 바꿔 공유 |
| `renderStats()` | 최신월 착공/인허가 합계와 전년동월비를 상단 카드에 표시 |
| `renderHeadline()` / `renderRegions()` | 각각 합계 차트 / 시도별 차트 그리드를 그림. 차트는 실제 표시 폭(px, `boxWidth()`)으로 그려 축 글자 크기가 화면과 무관하게 일정하며, 창 폭이 바뀌면 다시 그림. 분기 라벨이 겹칠 만큼 좁으면 6·12월 → 12월만 표시 |
| `renderTable()` | 월별 상세표를 HTML 테이블로 생성(최신월이 위로 오도록 역순 정렬) |
| `downloadXlsx({title, hdr, rows, footer, sheetName, fileName})` | 두 엑셀 다운로드가 공유하는 공용 함수. 제목행 + 네이비 헤더행 + 데이터행(+합계행)으로 `.xlsx`를 만들어 다운로드 |
| `exportExcelTrend()` | 월별 상세표와 동일한 내용을 `downloadXlsx()`로 내보냄 |
| `makeDropdown(root, {placeholder, allLabel, unitWord, groups, selected, onChange})` | 체크박스 목록이 펼쳐지는 다중선택 드롭다운(시도·시군구 공용). 선택 상태는 넘겨받은 `Set`을 직접 갱신. 바깥 클릭·Esc로 닫힘 |
| `buildQuery(cols)` | 열 목록(지역별 착공·인허가 배열)과 기간으로 월별 행·선택지역 합계 열·기간 합계 행을 계산 |
| `selectCols(state)` | 선택 상태(`q` 또는 `cq`)에서 시·군·구가 선택되어 있으면 `SUB`(원자료 연면적), 아니면 `DATA`(시도 공식 통계, 현재 지표)로 열 목록을 구성 (두 조회 공용) |
| `queryTable()` | `selectCols(q)` 결과로 `buildQuery()` 호출 |
| `renderQuery()` | 조회 조건 요약(기간 합계), 안내 문구(`showSubNote()`), 결과 표(`renderTableInto()`)를 렌더링 |
| `setupControls(state, ids, minIdx, onChange)` | 시도·시군구 드롭다운, 기간 선택 박스(월 인덱스 `minIdx` 이상), 표 펼치기 버튼을 상태 객체에 연결 (두 조회 공용). 시도를 해제하면 그 시도의 시·군·구 선택도 자동 해제, 시작월이 끝월보다 늦어지지 않도록 자동 보정 |
| `initQuery()` | 「지역별 조회」 컨트롤·엑셀 버튼 초기화 |
| `renderCumChart(t)` | 누적 조회 결과를 과거→최근 순으로 뒤집어 `buildChart()`로 그래프 표시. `buildChart()`는 `opts.months`(x축 월 목록)·`opts.unit`·`opts.tipLabel`을 받아 다른 기간·단위에도 재사용 |
| `cumTable()` / `renderCum()` / `initCum()` | 「지역별 누적 조회」: 기준월마다 `windowSum()`으로 직전 `CUM_WIN`(=18)개월 합계를 계산해 표·요약(마지막 기준월 누적)·엑셀을 처리 |
| `yoy(arr)` | 배열의 마지막 값과 13칸 전(전년 동월) 값을 비교해 증감률(%) 계산 |

### 상태 관리
- 전역 변수 `metric` (`'area'` 또는 `'count'`) 하나로 화면 전체(카드·차트·표·지역별 조회·엑셀)의 기준 지표가 결정됩니다.
  지표 버튼을 누르면 `metric` 값을 바꾸고 `renderAll()`을 다시 호출해 전체를 재렌더링하는 단순 구조입니다. (시·군·구 조회는 항상 연면적입니다.)
- 「지역별 조회」의 선택 상태는 전역 객체 `q = { regions: Set(시도), subs: Set("시도|시군구"), from: 월인덱스, to: 월인덱스 }`에 담깁니다.
- 「지역별 누적 조회」는 같은 형태의 별도 객체 `cq`를 써서 두 조회의 선택이 서로 영향을 주지 않습니다. 누적 개월 수는 상수 `CUM_WIN`(18) 하나로 정해집니다.
- 별도의 상태 저장(로컬스토리지, 쿠키, 세션)은 사용하지 않습니다. 새로고침하면 항상 초기값(`metric='area'`, 표 접힘)으로 돌아갑니다.

## 4. DB 사용 여부 및 상세 (중요)

**사내/외부 데이터베이스에 전혀 연결하지 않습니다.**

- 조회(SELECT), 수정(INSERT/UPDATE/DELETE) 등 어떠한 CRUD 동작도 없습니다.
- 접근하는 테이블이 존재하지 않습니다.
- 페이지가 표시하는 모든 수치는 파일 안에 **정적으로 박혀있는 값**이며, 페이지를 열 때마다 매번 동일한 값이 보입니다(수동으로 파일을 갱신하기 전까지).
- 이는 사이트 전체(`halla-yn-construction-status` 저장소)의 공통 설계 방식입니다 — 서버/DB 없이 정적 파일만으로 GitHub Pages에서 서빙됩니다.

## 5. 외부 API 사용 여부 (중요)

### 5-1. 배포된 페이지가 런타임에 호출하는 API
**없습니다.** `trend.html`이 브라우저에 로드된 이후, 실행 중에 어떤 외부 서버로도 데이터 요청(fetch/XHR/AJAX)을 보내지 않습니다. 모든 통계 수치는 위에서 설명한 `DATA`·`SUB` 상수로 이미 파일 안에 포함되어 있습니다.

### 5-2. 외부 CDN 리소스 (데이터 API 아님, 라이브러리 로드)
```html
<script src="https://cdn.jsdelivr.net/npm/exceljs@4.4.0/dist/exceljs.min.js"></script>
```
- **ExcelJS**(오픈소스 JS 라이브러리) 한 개만 jsDelivr CDN에서 불러옵니다.
- 용도: "EXCEL 다운로드" 버튼을 눌렀을 때 **브라우저 안에서** 엑셀 파일을 생성하기 위함입니다. 외부로 데이터를 전송하지 않고, 순수하게 클라이언트 사이드에서 파일을 만들어 로컬로 다운로드시킵니다.
- API 키나 인증 정보가 전혀 필요 없는 공개 라이브러리입니다.

### 5-3. 데이터 최초 수집 시 (일회성, 배포 코드에는 미포함)
현재 파일에 박혀있는 수치는 아래 과정으로 **한 번만** 수집해서 파일에 붙여넣은 것이며, 이 호출 코드 자체는 `trend.html`에 들어있지 않습니다(수집용 스크립트는 로컬 작업 후 폐기).

- **출처**: 국토교통부 통계누리(stat.molit.go.kr)의 공개 통계 조회 엔드포인트
  ```
  https://stat.molit.go.kr/portal/stat/data.do?formId=2202&styleNum=838&apprYn=Y&startDate=202109&endDate=202608   (착공)
  https://stat.molit.go.kr/portal/stat/data.do?formId=2200&styleNum=839&apprYn=Y&startDate=202109&endDate=202608   (허가)
  ```
- **인증 방식**: **API 키·로그인 불필요**. 누구나 접근 가능한 공공 통계 조회 엔드포인트로, HTTP GET 요청에 `Referer` 헤더만 포함하면 응답합니다.
- **API 특성상 제약**: 한 번의 조회에 최대 5년(60개월)까지만 가능해, 조회기간을 최근 60개월(현재 2021-09~2026-08)로 맞춰 둡니다.
#### 시·군·구 데이터(`SUB`) 출처 — 건축HUB 대용량 원자료 파일 (2026-09-29 최초 수집, 2026-10-07 갱신)
- **출처**: 국토교통부 건축HUB(hub.go.kr) → 원하는대로 건축데이터 → **대용량 데이터 제공**. 세움터 원자료를 매월 파일로 공개하는 서비스이며 매월 20일에 전월분까지 갱신됩니다.
  - 「국토교통부_건축인허가_기본개요 (2026년 08월).zip」 약 440MB(압축 해제 1.7GB, 전국 약 651만 건, `|` 구분 텍스트 41개 필드)
  - 「국토교통부_주택인허가_기본개요 (2026년 08월).zip」 약 7.5MB(29개 필드) — 주택법 사업계획승인(대형 아파트 단지)은 건축허가가 아니라 이 파일에 있어 함께 사용
- **인증 방식**: **로그인·API 키 불필요**, 공공데이터포털 기준 이용허락범위 "제한 없음". 페이지 조회 후 `POST /cmm/fms/fileOpnDown.do`(파일 ID + 페이지의 CSRF 토큰)로 내려받습니다.
- **집계 규칙**(검증을 거쳐 정함):
  1. 건축인허가는 건축구분 **"신축"만** 사용합니다. 원자료의 "연면적"은 건물 전체 면적이라, 증축·대수선·용도변경까지 더하면 공식 통계의 10~28배로 부풀기 때문입니다.
  2. 주택인허가는 **세대수·동수가 있고 세대당 면적이 10~1,000㎡인 행만** 쓰고, 필지·세대수·면적이 같은 행은 한 사업으로 묶습니다(사업승인일은 묶음의 첫 기록, 착공일은 묶음 안에서 실제 착공일이 적힌 기록 기준)(변경 기록이 같은 사업으로 여러 번 나오며, 세대 0·면적 수십억㎡ 같은 비정상 행이 섞여 있음).
  3. 인허가 월 = 건축허가일(주택은 사업승인일), 착공 월 = **실제 착공일**(주택은 실제 착공일이 비어 있으면 제외. 착공예정일은 계획일이라 쓰지 않음).
  4. 시군구코드로 묶고, 경남 창원시(5개 구)·경북 포항시(2개 구)는 시 단위로 합산합니다.
- **검증 결과**(원자료 합계를 시도로 다시 더해 공식 통계와 비교, 2021-09~2026-08): 인허가 연면적은 공식의 **76~90%**, 월별 상관 **0.87~0.96**으로 잘 맞습니다. 착공 연면적은 주택 사업의 실제 착공일 기록이 드물어 공식의 **45~67%**, 상관 0.41~0.81로 적게 잡힙니다. 시도별 수치는 `SUB_VALID`에 있습니다.
- 집계 스크립트(Python, 표준 라이브러리만 사용)는 작업 세션의 임시 폴더에서 실행했으며 저장소에는 포함되어 있지 않습니다.

- **결론**: 이 페이지와 관련해 어디에도 개인 발급 API 키나 인증 토큰이 저장·사용된 적이 없습니다.

> 참고: 같은 저장소 내 다른 실험(구·군 단위 착공현황 상세조회 시도)을 위해 국토교통부 "건축HUB" **API** 개인 인증키를 발급받아 테스트한 적이 있으나, 그 키는 이 파일 어디에도 포함되어 있지 않습니다. 위 시·군·구 데이터는 인증키가 필요 없는 **대용량 파일**로 만든 것이며 API 키와 무관합니다.

## 6. 실행 환경 및 방법

### 필요 패키지 / 라이브러리
- **없음(빌드 불필요)**. npm install, pip install 등 어떤 패키지 설치도 필요 없습니다.
- 유일한 외부 의존성은 브라우저가 런타임에 자동으로 불러오는 ExcelJS(CDN)이며, 로컬에 설치할 필요가 없습니다.

### 실행 방법
1. **로컬에서 미리보기**: `construction/trend.html` 파일을 더블클릭하거나 브라우저 주소창에 `file:///...` 경로로 열면 바로 동작합니다(서버 구동 불필요).
2. **배포**: 이 저장소는 **GitHub Pages**로 서빙됩니다. `main` 브랜치에 파일을 커밋·푸시하면 별도 빌드 과정 없이 몇 분 내로 아래 URL에 자동 반영됩니다.
   - https://jongkukwon-ai.github.io/halla-yn-construction-status/construction/trend.html
3. **데이터 갱신 방법**(월 1회 정도 권장):
   - 시도 공식 통계: 위 5-3의 두 URL을 `startDate`/`endDate`를 최신 구간으로 바꿔 다시 조회 → 응답 JSON을 지역×월×지표별로 집계 → 파일 안의 `const DATA = {...}` 리터럴을 새 값으로 교체.
   - 시·군·구: 매월 20일 이후 건축HUB 대용량 파일 두 개를 새로 받아 5-3의 집계 규칙대로 다시 집계 → `const SUB = ...`, `const SUB_VALID = ...`를 교체. **`SUB`의 월 범위는 반드시 `DATA.months`와 같게 맞춰야 합니다**(두 배열을 같은 인덱스로 씁니다).
   - 교체 후 커밋·푸시.

## 7. 주의사항 (유지보수 참고)

1. **조회기간 60개월 고정**: 국토교통부 API 자체가 1회 조회 최대 5년만 허용하므로, 60개월치만 담겨 있습니다. 기간을 늘리려면 여러 번 나눠 조회해 이어붙여야 합니다.
2. **데이터는 스냅샷입니다 — 실시간 아님**: 페이지를 열 때마다 항상 마지막으로 갱신한 시점의 고정값을 보여줍니다. 최신 통계를 반영하려면 반드시 6장의 절차대로 수동 갱신해야 합니다.
3. **최근 구간은 잠정치**: 원 통계 기준 2026-01~2026-08 자료는 "잠정치(p)"로, 이후 확정 공표 시 수치가 소급 정정될 수 있습니다.
4. **시·군·구 값은 공식 통계가 아님**: 국토부 공식 착공·인허가 통계는 시도 단위까지만 있습니다(국토부 통계누리·KOSIS 확인. 세움터의 시군구 집계 화면은 로그인 필요). 그래서 「지역별 조회」의 시·군·구 값은 건축HUB 원자료를 자체 집계한 연면적이며, 시도 합계가 공식값과 다릅니다(인허가 약 76~90%, 착공 약 45~67%). 화면과 엑셀 제목에 이 점이 표시되며, 시·군·구 합계를 공식 시도 통계와 바로 비교하면 안 됩니다.
5. **아파트 통계 아님**: 상업·공업 등을 포함한 전체 건축물 기준이라, 시멘트 수요와 직결되는 아파트만 보고 싶다면 별도 탭(「영남지역 착공현황」, `construction/index.html`)을 참고해야 합니다. 두 페이지의 숫자를 서로 비교/합산하면 안 됩니다.
6. **외부 CDN 의존**: ExcelJS를 jsDelivr CDN에서 불러오므로, 사내망에서 외부 CDN 접속이 차단되어 있으면 "EXCEL 다운로드" 버튼만 동작하지 않습니다(차트·표 등 나머지 기능에는 영향 없음). 필요 시 해당 CDN 도메인(`cdn.jsdelivr.net`)을 방화벽 허용 목록에 추가해야 합니다.
7. **에러 처리/테스트 코드 없음**: 단일 정적 파일로, 별도의 자동화 테스트나 예외 처리 로직은 최소한으로만 되어 있습니다(ExcelJS 로드 실패 시 alert 정도). 데이터 리터럴을 수작업으로 교체할 때 JSON 문법 오류가 없는지 직접 확인해야 합니다.
8. **개인정보 없음**: 이 페이지가 다루는 데이터는 정부 공개 집계 통계뿐이며, 개인정보·사내 기밀 정보는 포함되어 있지 않습니다.
